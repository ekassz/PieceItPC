# PieceItPC
Building a PC can be an overwhelming process, especially for beginners. PieceItPC is designed to simplify this experience by providing a user-friendly app that guides users through every step of assembling their own computer.

### Features:

🔍 Part Scanning – Identify PC components using your phone’s camera and get tailored installation guidance.

📺 YouTube Integration – Automatically fetch relevant tutorial videos to assist with component installation.

📂 Firebase Integration – Securely store user data, track build progress, and manage user-generated content.

💬 Community Sharing – Share completed builds and get insights from other PC builders.
